LabTrack ahora tiene servidor y base de datos.

Para utilizar la versión actual:

  1. Instala Node.js 24 o posterior.
  2. Abre la carpeta del proyecto en VS Code.
  3. Ejecuta npm start en la terminal. En Windows también puedes abrir Iniciar_LabTrack.bat.
  4. Abre el sistema con usuario admin y contraseña 1234. Si ya utilizabas otra cuenta, ejecuta npm run demo:admin con el servidor detenido para preparar ese acceso sin borrar el inventario.
Abrir LabTrackDeja la terminal abierta mientras utilizas el sistema. Consulta README.md para más información.
